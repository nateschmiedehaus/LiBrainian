# Implementation Plan — Issue 716 (Replace Invalid Eval Corpus)

## Acceptance criteria before re-queueing #716
1. `librarian external-repos sync --verify --json --repos-root eval-corpus/external-repos` finishes with `errors: 0` and reports only real GitHub aliases from `manifest.json`.
2. `node scripts/external-ground-truth.ts --reposRoot eval-corpus/external-repos --maxRepos 5` emits `.librarian-eval/{manifest,ground-truth}.json` for every processed repo; a follow-up `rg -n "\"repoId\":" eval-corpus/external-repos/*/.librarian-eval/manifest.json` shows ≥15 repos with machine-verifiable metadata.
3. `npm run smoke:external:sample` completes using the cloned aliases (typedriver-ts, token-explorer-py, tlsproxy-go by default) and attaches `*.librarian-eval` metadata in its artifact summary.
4. `rg "eval-corpus/repos" src/ scripts/ docs/` returns only historical documentation references; all live gates/tests read repo roots from `eval-corpus/external-repos` or the manifest helper.
5. Publish-gate + patrol docs list `external-repos sync → external-ground-truth → smoke` as the canonical preflight for any quality evidence.

## Scope split & deliverables

### Track A — Corpus sync + fixture validation (owner: infra)
Goal: make `external-repos` clones a first-class prerequisite so automation stops invoking stale fixtures.
- **Files**: `src/cli/commands/external_repos.ts`, `scripts/external-repo-smoke.ts`, `scripts/repo-folder-audit.mjs`, `docs/TEST.md`, `docs/librarian/REALITY_VERIFICATION.md`.
- **Actions**:
  - Add `--require-ground-truth` validation to `librarian external-repos sync --verify` so CI fails if `.librarian-eval/manifest.json` is missing after sync.
  - Teach `scripts/repo-folder-audit.mjs` and `docs/TEST.md` to treat `eval-corpus/external-repos/*/.librarian-eval` as required tracked artifacts (manifest only; repos remain untracked).
  - Update test docs/real-world evidence policy to say "run `external-repos sync --verify` before patrol/eval".
- **Exit**: new guard blocks missing `.librarian-eval` directories before any eval harness kicks off.

### Track B — Ground truth generation pipeline (owner: eval tools)
Goal: emit reproducible `.librarian-eval` bundles straight from the real repos.
- **Files**: `scripts/external-ground-truth.ts`, `package.json` (new npm script `ground-truth:external`), `docs/librarian/README.md`, `docs/librarian/CONVERSATION_INSIGHTS.md` (append runbook), `state/m0/self-dev-proof.json` (new proof artifact reference).
- **Actions**:
  - Wrap `scripts/external-ground-truth.ts` in an npm script (e.g., `npm run ground-truth:external -- --maxRepos 10`).
  - Check outputs into `state/m0/` (manifest of which repos received ground truth + timestamps) so publish gate can cite evidence.
  - Document the pipeline (sync → ground-truth → smoke) inside librarian README and status docs; link to manifest and alias mapping.
- **Exit**: at least 15 aliases in manifest have current `.librarian-eval/*` files generated by the script and referenced in state evidence.

### Track C — Gate migration to real repos (owner: retrieval/process)
Goal: stop reading synthetic fixtures anywhere in production code.
- **Files**: `src/constructions/processes/bootstrap_quality_gate.ts`, `query_relevance_gate.ts`, `context_pack_depth_gate.ts`, `src/api/packs.ts`, `src/query/scoring.ts`, `src/api/pack_sources/external_eval_corpus.ts`, `src/__tests__/*external_repo*.test.ts`, `scripts/eval-testing-discipline.ts`, `scripts/agent-patrol.mjs`.
- **Actions**:
  - Create a shared helper (e.g., `src/evaluation/external_repo_paths.ts`) that resolves clones via `eval-corpus/external-repos/repos/<alias>` and rejects missing `.librarian-eval` metadata.
  - Update every process/test that currently hardcodes `eval-corpus/repos/...` to call the helper with alias lists defined in `manifest.json` (TypeScript + Python for bootstrap gate, polyglot coverage for patrol/journey, etc.).
  - Extend `scripts/eval-testing-discipline.ts` to assert that at least one repo per language bucket has non-zero ground-truth queries; fail-fast otherwise.
  - Refresh unit/integration tests (`src/__tests__/external_repo_smoke.integration.test.ts`, `src/constructions/processes/__tests__/*`) to stub the helper so they no longer depend on synthetic fixture directories.
- **Exit**: grep check (acceptance criterion #4) passes, and gates/patrol/test harnesses reference only `external-repos` derived paths at runtime.

### Track D — Governance + issue hygiene (owner: management)
Goal: keep #716 actionable after re-queueing.
- Attach this plan + acceptance criteria to issue #716, remove `agent:manual-review-needed`, and re-label as `agent:actionable` only after Track A evidence (sync guard) is merged.
- Document progress checkpoints (`state/m0/issue-716/*.md`) so automation can resume from the last green stage instead of rerunning everything.
- Ensure per-issue quality analysis is configured to use at least 3 external repos per run (hook `node scripts/issue-quality-analysis.mjs 716 --description "external corpus gate" --repos-root eval-corpus/external-repos`).

## Execution order & dependencies
1. Track A unblocks everything else (ensures clones/fixtures exist).
2. Track B can run in parallel once Track A clones succeed; Track C depends on B because gates need `.librarian-eval` data to stay deterministic.
3. Track D is ongoing; once Tracks A-C finish we can update issue #716 status and schedule publish-grade verification (`npm run test:agentic:strict`).

## Risk log
- **Disk pressure**: cloning 23 repos plus AST outputs may blow local disk. Mitigation: enforce `--max-repos` slices in scripts and document clean-up commands.
- **Manifest drift**: ensure every manifest update (commit or timestamp) is referenced in state evidence; add repo-folder audit ignore for clones but not for `.librarian-eval` files.
- **CI runtime**: smoke/tests on real repos may exceed existing timeouts; plan includes `scripts/external-repo-smoke.ts` timeout knobs and suggests starting with `npm run smoke:external:sample` before the `:all` profile.
